# kinmon

このリポジトリには、ブラウザだけで動く静的Webアプリを収録しています。

## アプリ一覧

- [`index.html`](./index.html) — 💰 KINMON ORACLE（金運モンスター神託）：エンタメ系の金運診断アプリ
- [`ai-sales-app/`](./ai-sales-app/) — 🚀 AI SALES PILOT（AI物販オートパイロット）：物販ビジネスの
  仕入れ〜出品〜利益分析〜経営改善を一元管理する業務ツール。詳細は
  [`ai-sales-app/README.md`](./ai-sales-app/README.md) を参照してください。

各アプリはビルド不要で、対応する `index.html` をブラウザで開くだけで利用できます。
