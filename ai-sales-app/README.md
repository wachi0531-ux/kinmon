# 🚀 AI SALES PILOT（AI物販オートパイロット）

物販（せどり・輸入転売・EC等）ビジネスの **仕入れ判断 → 出品 → 在庫管理 → 利益分析 → 経営改善** を
一つの画面で回すための、ブラウザだけで動く業務管理アプリです。サーバー不要・インストール不要で、
`index.html` を開くだけで使えます。

> ⚠️ **収益を保証するツールではありません。**
> このアプリは意思決定を助けるシミュレーター／管理ツールです。月利50万〜100万円という金額は、
> 相応の元手資金・仕入れ判断力・作業量・市場環境が揃って初めて到達しうる水準であり、
> 誰でも自動的に到達できるものではありません。無理のない資金計画で取り組んでください。

## できること（機能一覧）

| タブ | 内容 |
|---|---|
| 📊 ダッシュボード | 当月の売上・仕入・利益、月利50万/100万円ゴールへの進捗、月次利益推移グラフ、カテゴリ別利益シェア |
| 🔍 商品リサーチ | 仕入原価・送料・販売手数料まで含めた利益/利益率/ROIを自動計算し、仕入れ可否をAIが判定 |
| 📦 仕入・在庫管理 | 商品ごとのステータス管理（検討中→仕入済→出品中→売却済）、一覧・編集・削除、絞り込み |
| 🏷️ 出品・価格戦略 | 出品文（タイトル・本文）のテンプレート自動生成、競合価格をもとにした推奨価格の計算 |
| 📈 売上分析 | 月別実績、販路別利益シェア、利益トップ商品ランキング |
| 🤖 AIアドバイザー | 蓄積データから在庫滞留・カテゴリ偏り・低採算商品などのリスクを自動診断（オフラインで常時利用可）。任意でお手持ちのAI APIキーを接続すればチャット相談も可能 |
| 🗺️ ロードマップ | 目標月利からの逆算シミュレーター、0ヶ月目〜法人化検討までのフェーズ別チェックリスト |
| ⚖️ 法律・税金 | 古物商許可・特定商取引法・確定申告・消費税・インボイス制度など、必ず確認すべき論点の要約 |
| ⚙️ 設定 | プラットフォーム手数料の編集、AI連携設定、データのバックアップ（JSON）/復元/削除 |

## 使い方

1. `index.html` をブラウザで直接開く（ダブルクリックでOK）、または GitHub Pages 等で公開する。
2. 初めての場合は「ダッシュボード」下部の **サンプルデータを投入** で使用感を確認できます。
3. 「商品リサーチ」で仕入れ候補の利益シミュレーションを行い、良ければ「在庫に登録」。
4. 「仕入・在庫管理」でステータスを更新（仕入れ済み→出品中→売却済み）していくと、
   ダッシュボードや売上分析に自動で反映されます。
5. 月1回「AIアドバイザー」で診断レポートを確認し、次の一手を決める。

データはすべて **お使いのブラウザの localStorage** に保存されます（サーバーには送信されません）。
定期的に「設定」タブからJSONバックアップを取得することを推奨します。

## AI連携（任意・実験的機能）

「設定」タブでご自身のAnthropic / OpenAI互換APIキーを登録すると、「AIアドバイザー」タブの
チャットからAIに直接相談できます。

- APIキーは **この端末のブラウザ内にのみ保存** され、入力後は選択したAIプロバイダーへ
  ブラウザから直接送信されます。運営者のサーバーを経由することはありません。
- ブラウザから外部APIへの直接アクセスは、プロバイダー側のCORSポリシーにより
  接続できない場合があります。接続できない場合も、オフラインで動作する
  「経営診断レポート」機能は常にご利用いただけます。
- 共有端末で利用した場合は、利用後に「設定」タブからAPIキーを削除してください。

## 手数料・税制などの数値について

プラットフォーム手数料（Amazon/メルカリ/ヤフオク!等）や税制の記述は、いずれも
**執筆時点の一般的な目安** です。実際の手数料・法制度は変更されることがあるため、
仕入れ判断や確定申告等の前に、必ず各プラットフォームの公式情報および
税理士・行政書士・警察署（生活安全課）等の専門家に確認してください。

## 技術構成

- 単一の `index.html`（HTML/CSS/バニラJavaScript）で完結。ビルドや依存パッケージは不要です。
- グラフはライブラリを使わず `<canvas>` に直接描画しています。
- データ永続化は `localStorage`。エクスポート/インポートはブラウザのFile APIを使用しています。
