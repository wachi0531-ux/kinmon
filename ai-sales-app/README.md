# 🚀 AI SALES PILOT（AI物販オートパイロット）

物販（せどり・輸入転売・EC等）ビジネスの **仕入れ判断 → 出品 → 在庫管理 → 利益分析 → 経営改善** を
一つの画面で回すための、ブラウザだけで動く業務管理アプリです。サーバー不要・インストール不要で、
`index.html` を開くだけで使えます。

> ⚠️ **収益を保証するツールではありません。**
> このアプリは意思決定を助けるシミュレーター／管理ツールです。月利50万〜100万円という金額は、
> 相応の元手資金・仕入れ判断力・作業量・市場環境が揃って初めて到達しうる水準であり、
> 誰でも自動的に到達できるものではありません。無理のない資金計画で取り組んでください。

## できること（機能一覧）

| タブ | 内容 |
|---|---|
| 📊 ダッシュボード | 当月の売上・仕入・利益、月利50万/100万円ゴールへの進捗、月次利益推移グラフ、カテゴリ別利益シェア |
| 🔍 商品リサーチ | 仕入原価・送料・販売手数料まで含めた利益/利益率/ROIを自動計算し、仕入れ可否をAIが判定。売買の差額がしきい値（既定¥2,000・設定タブで変更可）以上になるとポップアップで通知。楽天市場APIと連携したウォッチリストの自動巡回にも対応（後述） |
| 📦 仕入・在庫管理 | 商品ごとのステータス管理（検討中→仕入済→出品中→売却済）、一覧・編集・削除、絞り込み |
| 🏷️ 出品・価格戦略 | 出品文（タイトル・本文）のテンプレート自動生成、競合価格をもとにした推奨価格の計算 |
| 📈 売上分析 | 月別実績、販路別利益シェア、利益トップ商品ランキング |
| 🤖 AIアドバイザー | 蓄積データから在庫滞留・カテゴリ偏り・低採算商品などのリスクを自動診断（オフラインで常時利用可）。任意でお手持ちのAI APIキーを接続すればチャット相談も可能 |
| 🏢 AI組織 | AI社長（週次経営会議レポート）・AI経理（年間損益と確定申告/消費税ラインの照合、簡易仕訳CSV出力）・AI社員（リサーチ担当・出品担当・価格担当・在庫担当・カスタマー対応担当の5役割）で構成。詳細は下記「AI組織について」を参照 |
| 🗺️ ロードマップ | 目標月利からの逆算シミュレーター、0ヶ月目〜法人化検討までのフェーズ別チェックリスト |
| ⚖️ 法律・税金 | 古物商許可・特定商取引法・確定申告・消費税・インボイス制度など、必ず確認すべき論点の要約 |
| ⚙️ 設定 | プラットフォーム手数料の編集、差額アラートのしきい値、AI連携設定、データのバックアップ（JSON）/復元/削除 |

## 使い方

1. `index.html` をブラウザで直接開く（ダブルクリックでOK）、または GitHub Pages 等で公開する。
2. 初めての場合は「ダッシュボード」下部の **サンプルデータを投入** で使用感を確認できます。
3. 「商品リサーチ」で仕入れ候補の利益シミュレーションを行い、良ければ「在庫に登録」。
4. 「仕入・在庫管理」でステータスを更新（仕入れ済み→出品中→売却済み）していくと、
   ダッシュボードや売上分析に自動で反映されます。
5. 月1回「AIアドバイザー」で診断レポートを確認し、次の一手を決める。

データはすべて **お使いのブラウザの localStorage** に保存されます（サーバーには送信されません）。
定期的に「設定」タブからJSONバックアップを取得することを推奨します。

## AI連携（任意・実験的機能）

「設定」タブでご自身のAnthropic / OpenAI互換APIキーを登録すると、「AIアドバイザー」タブの
チャットからAIに直接相談できます。

- APIキーは **この端末のブラウザ内にのみ保存** され、入力後は選択したAIプロバイダーへ
  ブラウザから直接送信されます。運営者のサーバーを経由することはありません。
- ブラウザから外部APIへの直接アクセスは、プロバイダー側のCORSポリシーにより
  接続できない場合があります。接続できない場合も、オフラインで動作する
  「経営診断レポート」機能は常にご利用いただけます。
- 共有端末で利用した場合は、利用後に「設定」タブからAPIキーを削除してください。

## AI組織について（社長・経理・社員）

「AI組織」タブは、同じ在庫・売上データを3つの役割の視点から読み直す仕組みです。**AIが担当するのは分析・意思決定の材料づくり・文面の下書きまでで、実際に仕入れ代金を支払う・出品を公開する・価格を変更する・確定申告書を提出するといった「お金や契約が動く操作」は行いません。** 実行と最終承認は、事業の名義人であるあなた自身が行う前提の設計です（多くのプラットフォームが自動購入・自動出品ボットを規約で禁止していることに加え、実行した取引の法的・金銭的責任はAIではなく事業者本人に帰属するためです）。

- **AI社長**：週次の実績（先週比）、重点方針、¥30,000以上の仕入れ候補の承認待ちリストを表示
- **AI経理**：年間の累計売上・利益を、副業の確定申告ライン（所得20万円）・専業の基礎控除ライン目安（所得48万円）・消費税の課税事業者ライン（課税売上高1,000万円）と照合。「日付・摘要・勘定科目・区分・金額」形式の簡易仕訳CSVも出力可能
- **AI社員**：リサーチ担当（差額アラートの検出ログ）・出品担当（出品し忘れ）・価格担当（低ROI商品）・在庫担当（滞留在庫）・カスタマー対応担当（発送確認/値下げ交渉/状態質問/クレームへの返信ドラフト生成）の5役割

## 自動リサーチ（楽天市場API連携）について

「商品リサーチ」タブの下部から、キーワード＋想定売価のウォッチリストを登録すると、楽天市場の実売価格を自動で取得し、差額がしきい値以上ならリサーチ担当のログに記録します。**購入の自動実行はしていません**——見つけた候補は在庫に「仕入れ検討中」として登録されるだけで、実際に買うかどうかはユーザーの判断です。

- 対応は**楽天市場のみ**です。Amazon は個人が仕入れ目的で使える公式の商品検索APIが実質なく、メルカリ・ヤフオクは公式の商品検索APIを提供していないため、非公式スクレイピングは規約違反リスクが高く実装していません。
- [楽天ウェブサービス](https://webservice.rakuten.co.jp/) で無料登録すると発行される「アプリID」が必要です（この端末のブラウザにのみ保存）。
- 実装は **JSONP**（`<script>` タグでの読み込み）方式です。楽天の商品検索APIはブラウザからの`fetch()`に対してCORSヘッダーを返さずブロックされますが、`callback`パラメータによるJSONPには対応しているため、バックエンドサーバーなしで動作します。
  - そのため、**このファイルを直接ブラウザで開いている場合（またはご自身でホスティングした場合）は動作しますが、Claudeのアーティファクト（プレビュー）画面上ではスクリプト読み込みのセキュリティ制限により動作しません。** 自動リサーチを使う場合はローカルのファイルを直接開いてご利用ください。
- 自動スキャンは `setInterval` によるもので、**このタブを開いているブラウザタブが存在する間だけ**動作します。タブを閉じる・PCをスリープさせる等で停止します。「PCの電源を切っていても自動で探し続ける」ような、サーバー側で常時稼働する仕組みではありません。
- 楽天APIの無料枠のレート制限を考慮し、ウォッチリストの各キーワードは約1.1秒間隔で順番に問い合わせます。

## 手数料・税制などの数値について

プラットフォーム手数料（Amazon/メルカリ/ヤフオク!等）や税制の記述は、いずれも
**執筆時点の一般的な目安** です。実際の手数料・法制度は変更されることがあるため、
仕入れ判断や確定申告等の前に、必ず各プラットフォームの公式情報および
税理士・行政書士・警察署（生活安全課）等の専門家に確認してください。

## 技術構成

- 単一の `index.html`（HTML/CSS/バニラJavaScript）で完結。ビルドや依存パッケージは不要です。
- グラフはライブラリを使わず `<canvas>` に直接描画しています。
- データ永続化は `localStorage`。エクスポート/インポートはブラウザのFile APIを使用しています。
