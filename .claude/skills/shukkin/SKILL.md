# 出社ワークフロー(shukkin)

「出社」の一言で、個別のAI秘書スキル(mail-secretary / meeting-prep / task-tracker)を
順番に実行し、その日の仕事を始められる状態まで一気に整える統合ワークフローです。

毎回細かく指示を出す必要をなくすのが目的です。長い指示文を都度書かせず、この手順に沿って淡々と実行してください。

## 実行手順

1. **設定確認**:`ai-secretary/PROFILE.md` を読み、各業務の型を把握する(未設定項目があれば
   後の要約で一言注意喚起する程度に留め、処理は止めない)。
2. **メール確認・返信下書き**(mail-secretary の手順を実行):
   - Gmail未読メールを取得し、優先順位を付ける
   - 優先度の高いものから返信下書きをGmailに保存する
3. **今日の会議準備**(meeting-prep の手順を実行):
   - 今日のカレンダー予定を取得
   - 関連する過去資料をDriveから検索し、論点・確認事項・注意点を整理する
4. **残タスク確認**(task-tracker の手順を実行):
   - `ai-secretary/TASKS.md` を読み、未完了タスクを確認する
   - Gmail/Calendarの内容から新たに発生したタスクがあれば提案する(追加は確認のうえ)
5. **今日の優先順位を提示**:2〜4の結果を踏まえ、以下の形式で「今日の行動順序」をまとめる。
   ```
   ## 📬 メール
   - 要返信: N件(下書き作成済み)
   - 保留: N件(理由)

   ## 🗓 今日の会議
   - (時刻) 会議名:論点サマリ

   ## ✅ タスク
   - 今日やるべきこと(上位3〜5件)

   ## 🎯 今日の優先順位
   1. ...
   2. ...
   3. ...
   ```
6. 送信・イベント削除・タスクの自動完了など「取り消しづらい操作」は行わず、下書き・提案までに留める。
   最終判断と実行はユーザーに委ねる。

## 拡張について

同じ考え方で「退勤」「商談準備」「週次レビュー」などのトリガーも追加できます。
`.claude/skills/` に新しいスキルフォルダを作り、`ai-secretary/PROFILE.md` に対応する
「仕事の型」セクションを追記していく形で拡張してください。
