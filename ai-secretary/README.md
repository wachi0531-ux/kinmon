# AI秘書(Claude Code版)

Claude Codeを「質問に答えるAI」ではなく、自分のメール・カレンダー・ファイルを実際に見て
仕事を進める「専属AI秘書」として使うための構成です。

## 構成

```
ai-secretary/
├── README.md      ← このファイル
├── PROFILE.md      ← あなた固有の「仕事の型」(判断基準)。まずここを書き換える
└── TASKS.md        ← タスク一覧(task-tracker が読み書き)

.claude/skills/
├── mail-secretary/  ← メール係:未読メールの優先順位付け・返信下書き作成
├── meeting-prep/    ← 会議準備係:カレンダー確認+関連資料の読み込み+論点整理
├── daily-report/    ← 日報係:進捗・課題・明日の予定を作成
├── task-tracker/    ← タスク管理係:残タスクの確認・優先順位付け
└── shukkin/         ← 統合ワークフロー:「出社」の一言で上記を一括実行
```

## 使い方

1. **`ai-secretary/PROFILE.md` を自分用に書き換える**
   これが一番重要です。優先順位の付け方、メールのトーン、日報フォーマット、
   会議準備で見るべき観点などを、自分の言葉で書きます。ここに書いた内容がそのまま
   AIの判断基準になります。
2. 個別に使う場合はそのまま話しかけるだけで該当スキルが呼ばれます。
   - 「未読メール整理して、返信下書き作って」→ `mail-secretary`
   - 「今日の会議準備して」→ `meeting-prep`
   - 「日報書いて」→ `daily-report`
   - 「残タスク確認して」→ `task-tracker`
3. 一通り個別に試して問題なければ、**「出社」と話しかけるだけ**で
   メール確認→返信下書き→会議準備→残タスク確認→今日の優先順位提示、を一括実行します(`shukkin`)。

## 前提条件

- Gmail / Google Calendar / Google Drive のMCP連携が有効になっていること
  (未接続の場合は該当スキルがその旨を案内します)
- 送信・削除・共有などの「取り消しづらい操作」は行いません。すべて下書き・提案までで、
  最終確認と実行は人間(あなた)が行う設計です(`PROFILE.md` の禁止事項を参照)。

## 拡張の仕方

「退勤」「商談準備」「週次レビュー」「月末締め」など、業務の節目ごとにトリガーを増やせます。

1. 小さな反復業務を1つ選ぶ
2. 要件(誰に・何を・どんなトーンで)を `PROFILE.md` に書く
3. `.claude/skills/` に新しいスキルフォルダを作り、手順を書く
4. 実行→出力を確認→ルールを追加、を繰り返して安定させる
5. 安定したら `shukkin` のような統合ワークフローに組み込む

一度に完全自動化を目指さず、「AIが実行 → 人間が確認」の運用から始めてください。
